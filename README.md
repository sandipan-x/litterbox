# LitterBox

Cat litter calculator: how many litter boxes you need (the n+1 rule) and how many litter bags to buy each month, by litter type. Free tool.

## Features
- Litter box count via the n+1 rule
- Monthly litter-bag estimate by litter type
- Litter type compare cards + scoop schedule planner
